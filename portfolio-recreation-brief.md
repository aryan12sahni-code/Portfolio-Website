## 20. TECHNICAL IMPLEMENTATION NOTES

### Recommended Stack
- **Framework**: Next.js 14+ (App Router) or React + Vite
- **Styling**: Tailwind CSS + Framer Motion
- **3D**: Spline, Three.js, or pre-rendered WebP animations
- **Animations**: Framer Motion, GSAP, or CSS animations
- **Fonts**: Google Fonts or local (Inter/Space Grotesk)

### Key Libraries
- `framer-motion` - Page transitions, scroll animations
- `react-intersection-observer` - Scroll-triggered animations
- `@splinetool/react-spline` - If using Spline for 3D
- `react-scrollmagic` or custom scroll handler
- `clsx` / `tailwind-merge` - Conditional classes

### Performance Optimizations
- **Images**: Next/Image with WebP format
- **3D Character**: Consider video loop as fallback
- **Loading Screen**: CSS-only if possible
- **Lazy Loading**: Projects below fold
- **Code Splitting**: Route-based splitting

### Accessibility
- **Keyboard Navigation**: Full support
- **Screen Readers**: Proper ARIA labels
- **Focus Indicators**: Clear purple outline
- **Color Contrast**: WCAG AA compliant (white on dark)
- **Reduced Motion**: Disable complex animations

## 21. MOTION BEHAVIORS (Detailed)

### Loading Screen
- **Text Marquee**: 
  - Speed: ~60px/second
  - Direction: Right to left
  - No pause, seamless loop
  
- **Progress Bar**:
  - Duration: 5-6 seconds
  - Easing: ease-out or custom curve
  - Fill from left to right

### Character Animations
- **Idle State**: 
  - Subtle breathing motion (scale: 1.0 to 1.02)
  - 3-4 second cycle
  - Rotation: ±1-2 degrees

- **Scroll Parallax**:
  - Move rate: 0.5x scroll speed (slower)
  - Direction: Up as user scrolls down

### Timeline Entrance
- **Line Drawing**: 
  - Stroke animation from top to bottom
  - Duration: 1.2-1.5 seconds
  
- **Dot Appearance**:
  - Sequence: Top to bottom with 0.1s stagger
  - Scale: 0 to 1 with elastic easing
  - Glow: Fade in after scale

### Project Cards
- **Grid Entrance**:
  - Stagger: 0.1s per card
  - Fade + translate up (20-30px)
  - Duration: 0.4-0.5s per card

- **Hover**:
  - Scale: 1.02-1.03
  - Shadow: Increase blur + spread
  - Duration: 0.2s
  - Easing: ease-out

### Purple Orb/Cursor
- **Follow Behavior**:
  - Lag: 0.1-0.15s behind cursor
  - Easing: Custom spring or ease-out
  - Size change on hover over interactive elements
